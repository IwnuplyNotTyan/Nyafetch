## Install
### ❄️ Nix
```sh
nix run github:iwnuplynottyan/nyafetch
```

### 🎏 Arch-based
```sh
makepkg -si
```

### ⛏️ Manually
```sh
go mod download
go build -o nyafetch main.go
```
